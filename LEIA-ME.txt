OBSERVATÓRIO DA PRODUÇÃO CIENTÍFICA EM GEOECOLOGIA DAS PAISAGENS

Envie todos os arquivos desta pasta para a RAIZ do repositório GitHub Pages.
index.html = página inicial.
teses.html + dados.json = catálogo de teses e dissertações.
publicacoes.html + publicacoes.json = catálogo de artigos, livros e capítulos.
filiacao_academica.html + filiacao_dados.json = rede de orientação.

Para atualizar palavras-chave futuramente: edite os campos palavrasChave, termosIndexacao, fontePalavras e situacao em publicacoes.json, mantendo os demais campos.

Não abra o HTML diretamente no computador para testar o carregamento de JSON; publique em GitHub Pages ou servidor local.
